# 暗场显微镜图片区

这一区不是简单堆图，而是按“先认外形—再看光路—最后看结果”的学习顺序组织。

第一次打开时，先读：

- [00_看图导览/先看这五张图.md](00_看图导览/先看这五张图.md)
- [00_看图导览/图片索引与PPT用途.md](00_看图导览/图片索引与PPT用途.md)
- [99_来源与授权/来源与授权说明.md](99_来源与授权/来源与授权说明.md)

文件夹含义：

- `01_原理图`：最基础的透射暗场光路。
- `02_实物与核心部件`：真实装置或关键部件长什么样。
- `03_典型结构`：侧向照明、物镜型全内反射等结构变体。
- `04_典型成像`：最后看到的暗背景亮目标，以及数据如何变化。
- `05_现代扩展`：暗场与光谱、相机、数据立方体等现代模块的组合。
- `99_来源与授权`：整页渲染图、提取脚本、页码和授权边界。

一句话认识暗场显微镜：它通常不是一台外形完全不同的显微镜，而是普通光学显微镜加上特殊照明部件；关键改变发生在照明光路，不在目镜外壳。
